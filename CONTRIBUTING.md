# Mitwirken

Beiträge zu einem reproduzierbaren Schweizer Nebenkosten-Prüfagenten sind willkommen.

## Voraussetzungen

Das Projekt ist aktuell eine dokumentbasierte Agent-Anweisung. Für Beiträge zu `NK-Agent.md` sind keine Python-Abhängigkeiten nötig.

## Gute erste Beiträge

- Anonymisierte Testfälle für Garaio-REM-Exporte ergänzen
- Beispiele für korrekte und fehlerhafte Nebenkostenbuchungen sammeln
- Mehrjahres-, Mengen- und Verteilschlüssel-Fälle dokumentieren
- Ergebnisse mit Zeile, Konto, Betrag und Zeitraum nachvollziehbar beschreiben
- Regeln auf Widersprüche, Mehrdeutigkeiten und fehlende Prüfgrundlagen prüfen
- Typografie, Struktur oder deutsche Fachbegriffe verbessern

## Pull Requests

1. Repository forken und einen eigenen Branch erstellen.
2. Eine kleine, fachlich begrenzte Änderung umsetzen.
3. Bei Fachregeländerungen eine anonyme oder synthetische Quelle ergänzen.
4. Das Ergebnis mit einem oder mehreren Beispieldatenfällen prüfen.
5. Einen Pull Request mit Annahme, Prüfungsergebnis und bekannten Grenzen erstellen.

## Datenschutz und fachliche Grenzen

Keine Daten laufender Liegenschaften, Mietenden, Rechnungen oder Bankverbindungen veröffentlichen.

Prüfergebnisse dürfen keine rechtlich verbindliche Feststellung darstellen. Fachliche Annahmen, Unsicherheiten und fehlende Nachweise müssen ausdrücklich gekennzeichnet werden.
